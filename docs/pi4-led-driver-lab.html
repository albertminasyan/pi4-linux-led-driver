Linux LED driver on Raspberry Pi 4: from toolchain to blinking LED

You will cross-compile mainline Linux 7.2.4 on a Debian 13 VM, put it on an SD card with Raspberry Pi OS Lite, then build a kernel module and a user program that switch an LED on GPIO17 through /dev/led0. Tick each step as you finish it; your progress is kept in this browser.

Before you start: every dd and mount command below uses the SD card device you set here. Run lsblk and confirm the size. Writing to the wrong disk destroys it. Your VM’s system disk is normally /dev/sda.

You need: Debian 13 VM (VirtualBox) with about 30 GB free, a good SD card (16 GB or more; a Samsung Pro Endurance 32 GB works well, counterfeit cards make dd extremely slow), a Raspberry Pi 4B with a serial console cable or an HDMI screen and keyboard, an LED with a series resistor on GPIO17 (physical pin 11) and ground, and a GitHub account.

See the companion flow diagrams for what happens inside the kernel during these steps: led_driver.ko control flow.
